# Mi primera tienda 🛍️

Proyecto de práctica hecho para aprender HTML, CSS y JavaScript desde cero.
Incluye:
- Sidebar de navegación
- Catálogo de productos
- Carrito de compras funcional (sin backend, todo en el navegador)

## Cómo verlo
Solo abre `mi-tienda.html` en tu navegador

## Qué aprendí
- Flexbox y CSS Grid
- Manipulación del DOM con JavaScript
- Cómo estructurar una app en secciones
